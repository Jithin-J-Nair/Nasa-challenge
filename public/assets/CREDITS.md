# Silent Fleet image and map credits

All images in this directory are hosted locally for performance and attribution continuity.

- `textures/moon-lroc-color.jpg` — derived from the **CGI Moon Kit** color map. Credit: NASA/GSFC Scientific Visualization Studio, using Lunar Reconnaissance Orbiter imagery and laser-altimeter data. Source: https://svs.gsfc.nasa.gov/4720. NASA asks for credit to NASA's Scientific Visualization Studio.
- `textures/mars-usgs-mola-map.jpg` — compressed working texture derived from the **Simple Cylindrical Projection, Mars 2000 datum, MOLA background** map. Credit: NASA/USGS. Source context: https://mars.nasa.gov/resources/6435/global-geologic-map-of-mars/.
- `images/voyager-context.jpg` — NASA/JPL-Caltech Voyager artist concept, PIA17049. Source: https://images.nasa.gov/details/PIA17049.
- `social/silent-fleet-og.jpg` — derivative social crop made for this site from the locally hosted CGI Moon Kit map above; credit NASA/GSFC Scientific Visualization Studio.
- `images/dossier-context-placeholder.svg` — original site placeholder. It is explicitly labelled and used only if a locally hosted context image fails to load.

NASA images are generally public domain in the United States unless otherwise marked by NASA. This project preserves the stated NASA credit lines and links to the source pages.
