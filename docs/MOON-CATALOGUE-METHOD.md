# Moon catalogue parsing method

**Source:** [NASA History Program, *Catalogue of Manmade Material on the Moon* (2012)](https://www.nasa.gov/wp-content/uploads/2024/02/final-catalogue-of-manmade-material-on-the-moon.pdf).

This result is generated by `scripts/parse-moon-catalogue.ts` from checked-in NASA PDF text cache. To refresh from an original downloaded PDF, run `MOON_CATALOGUE_PDF=path/to/final-catalogue-of-manmade-material-on-the-moon.pdf npm run catalogue:parse`; the script uses `pdftotext -layout` and the same parser.

## Counts from this parse

| method | result | treatment |
| --- | ---: | --- |
| (a) Material table lines | 111 | Every parsed object line, including references and indented/sub-item rows. |
| (b) Direct object/location rows | 98 | Excludes rows containing “see below/above/experiment” and marked sub-items. This is the **only count displayed in the UI**. |
| (c) Summed bracket quantities | 50 | Sums explicit `[n]` quantities only; it is not a unique-object total. |

The PDF is a hierarchical catalogue, not a flat inventory or a mass ledger. Blank, `UNKNOWN`, `Crashed`, and narrative locations are retained exactly as parsed. This site does not turn them into coordinates, infer missing locations, or claim a mass total.
